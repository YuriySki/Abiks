# Abiks — конвертер «белок ↔ музыка»

Реализация алгоритма из статьи

> L.T. Nadirova, A.V. Zhigailov. **How does a protein sound like: Converting amino acid sequences into music, and back.** *Heliyon* 12 (2026) e45432. https://doi.org/10.1016/j.heliyon.2026.e45432 (CC BY 4.0)

Аминокислотная последовательность переводится в музыку **дуплетным вырожденным кодом**: пара соседних остатков кодирует ноту, а свойства остатков и их окружения задают длительность, октаву, громкость, паузы, аккорды и темп. Поскольку код вырожден (каждой ноте соответствует 20–34 пары), музыку можно перевести **обратно** в аминокислотную последовательность — это тоже реализовано.

## Возможности

- **Белок → музыка**: FASTA или последовательность → нотация **ABC**, **MIDI**, **MusicXML**, JSON-модель партитуры и таблица «пара → звук» в стиле рисунков статьи.
- **Музыка → белок**: ABC-нотация (ноты, паузы, аккорды, форшлаги, динамика, акценты, крещендо) → одна или несколько аминокислотных последовательностей (по одной на голос) с отчётом о точности воспроизведения.
- Несколько цепей (четвертичная структура) → многоголосие: 1-я цепь — фортепиано, 2-я — акустическая гитара (со своей таблицей октав), далее — фортепиано.
- Веб-страница (`index.html`): конвертация в браузере, отрисовка нот (abcjs) и воспроизведение (WebAudio), таблица анализа, обратный перевод.
- Ноль зависимостей: Node.js ≥ 18, ES-модули; тесты — `node --test`.

## Быстрый старт

```bash
git clone https://github.com/YuriySki/Abiks && cd Abiks
node bin/abiks.js encode examples/hPrP91-230-nat.fasta --loc golgi -o prion.abc --midi prion.mid --xml prion.musicxml --table
node bin/abiks.js decode examples/rondo-alla-turca.abc -o mozart-protein.fasta --diffs --verify mozart-check.abc
node bin/abiks.js examples          # все примеры → examples/output/
node bin/abiks.js serve 8080        # веб-конвертер на http://localhost:8080/
npm test
```

`encode` принимает файл FASTA (несколько записей = несколько цепей) или последовательность прямо в аргументе. Опции: `--loc` — локализация белка (темп, табл. 8: `peroxisome plastid mitochondrion nucleus cytoplasm-nucleus aggresome cytosol cytoskeleton lysosome er golgi plasmalemma membrane-receptor secreted matrix`), `--bpm`, `--title`, `--instruments piano,guitar`, `--table` (печать таблицы анализа), `--json`, `--ignore-unknown`.

`decode` принимает ABC-файл. Опции: `--beam N` (ширина луча поиска, по умолчанию 64), `--seed N` (другой вариант последовательности), `--diffs` (список отличий), `--verify out.abc` (музыка, полученная из найденного белка), `--json report.json`.

### Использование как библиотеки

```js
import { proteinToMusic, scoreToAbc, scoreToMidi, scoreToMusicXml, parseAbc, musicToProtein } from './src/index.js';

const score = proteinToMusic('>insulin B\nFVNQHLCGSHLVEALYLVCGERGFFYTPKT\n>insulin A\nGIVEQCCTSICSLYQLENYCN', { localization: 'secreted' });
const abc = scoreToAbc(score);            // строка ABC
const midi = scoreToMidi(score);          // Uint8Array (.mid)
const xml = scoreToMusicXml(score);       // строка MusicXML
score.parts[0].elements                   // ноты/аккорды/паузы: pc, octave, midi, dur (1024 = целая), level, hairpin, accent, src…
score.parts[0].table                      // таблица «дуплекс → нота, Σ6σ, αav, βav, сдвиг длительности»

const back = musicToProtein(parseAbc(abc));
back.chains[0].sequence                   // найденная последовательность
back.chains[0].fidelity                   // { exact, total, attributes, diffs }
```

## Алгоритм (что именно реализовано)

Цепь читается от N-конца парами (дуплексами). Если остатков нечётное число, последний дуплекс — предпоследний + последний остаток (правило статьи).

| Свойство | Музыкальный признак | Таблица | Реализация |
|---|---|---|---|
| Пара остатков (без M и P) | Класс высоты (C…B) | 2 | 324 пары → 12 классов (31/20/31/20/32/33/20/34/20/32/20/31 вариантов) |
| Заряженные остатки D, E, C (укорачивают) и R, K, H (удлиняют) | Длительность | 3 | базовая 1/8; ×8, ×4, ×2.5, ×2, ×1.5 и обратные; предел 1/128 … лонга |
| Σσ шести ближайших остатков (гидрофильность) | Октава | 5 | окно = предыдущий, текущий и следующий дуплекс; отдельная шкала для гитары |
| Средние α- и β-индексы восьми ближайших остатков | Динамика p / mp / mf / f, крещендо / диминуэндо | 7 | окно внутри сегмента между G и P; сегмент ≤ 7 остатков → mf |
| Метионин + незаряженный остаток | Пауза | 4 | абсолютные длительности 1/128 … бревис |
| Метионин + заряженный остаток | Изменение длительности соседней ноты; два соседних таких дуплекса → две ноты | 3, прим. к табл. 2 | |
| Пролин + остаток | Аккорд от предыдущей ноты (36 типов) | 6 | корень — предыдущая нота; после паузы / в начале — следующая; иначе C |
| PP, PG, GP | Проходящие тоны и форшлаги | §2.5 | PG: 1 форшлаг, GP: 2, PP: 2 + проходящий тон; рядом с аккордом — добавляются к нему; между аккордами — повтор аккорда |
| Глицин в дуплексе; GG | Акцент; GG звучит как G только после G-дуплекса/паузы или перед P, иначе акцентирует предыдущий звук | §2.5–2.6 | |
| GM, MG рядом с P-дуплексом | Арпеджио (GM — вверх, MG — вниз) | 4 | |
| Локализация белка | Темп | 8 | 15 вариантов; по умолчанию Andante 76 |
| Число цепей | Фактура (моно-, би-, полифония) | §2.1 | фортепиано, гитара, … |

Нотация ABC пишется в стиле авторов: `L:1/1`, длительности как доли целой (`^A/8`, `D3/16`, `B2`), динамика `!p!…!f!`, акцент `!>!`, крещендо `!crescendo(! … !crescendo)!`, аккорды в квадратных скобках.

### Проверка по статье

Тесты (`test/`) сверяют реализацию с опубликованными примерами: таблица рис. 4a (прион hPrP 91–230, нативный и мутант P102L/P105L: ноты, октавы, длительности, αav = 0,365, βav = 1,313), рис. 5 (инсулин: обе цепи, все длительности 3/16, 3/32, 3/64, 3/128 и октавы гитары), рис. 1a (фрагмент Rab5: последовательность высот и пауза), фрагмент ABC на рис. 1b (паузы ML → 1/64, AM → 1, NM → 1/2, MM → 2; RE → 3/2; DE → 1/2; HD → 3/16; аккорды SR+PI, HR+YP), а также полноту таблицы 2 (все 324 пары ровно по одному разу).

### Уточнения реализации (места, где статья допускает несколько прочтений)

1. **Дробные изменения длительности** (табл. 3). ×1.5 → нота с точкой (1.5·D), ÷1.5 → точка от вдвое меньшей длительности (0.75·D); хранимое «целое» значение D не меняется (примеры GC → 3/16, 3/64 и QC/CT → 3/64 в рисунках). ×2.5 → D удваивается, нота играется с точкой (3·D; в статье RE: 1/2 → 3/2); ÷2.5 → D делится на 2, играется 0.375·D (в статье DK: 1/16 → 3/128, HD: 1/2 → 3/16). Для хранимого значения после ÷2.5 источники статьи расходятся (рис. 3a даёт D/2, фрагмент ABC на рис. 1b — D/4); принято D/2.
2. **Окно Σ6σ** — шесть остатков, центрированных на дуплексе (предыдущий, текущий, следующий); у концов цепи окно сдвигается внутрь; цепь короче 6 остатков → первая октава. Значение округляется до 0,1, граница интервала включается в верхнюю октаву (Σ6σ = 10 → четвёртая октава).
3. **Окно динамики** — 8 остатков, номинально дуплекс ± 3, сдвигается, чтобы уместиться в сегмент между G и P; дуплекс с G берёт сегмент второго остатка; GG и P-дуплексы собственного уровня не имеют (аккорд — от корневой ноты). Категория «α < 0,4, β ≥ 1,5» становится **mp**, если уровни до и после области одинаковы, и **крещендо/диминуэндо**, если различны (соответствует раскраске рис. 3a и 5).
4. **Аккорды** строятся от корня по стандартным интервалам (13-е без 11-й ступени), сдвигаются вниз по октавам, если выходят за диапазон инструмента; 9-е/11-е/13-е ступени — на октаву выше.
5. **Пары M-дуплексов** (`Mx + yM`): 30 сочетаний — по примечанию к табл. 2, 6 неупомянутых — по паре `xy` из табл. 2. Первая нота получает эффект `Mx`, вторая — `yM` (в ABC статьи: `B2 B3`).
6. **Модификатор `xM`** после аккорда/ноты изменяет только непосредственно предшествующий звук; `Mx` действует на следующий звук (паузы между ними пропускаются).
7. **Диапазоны**: ноты вне диапазона фортепиано (A0–C8) и гитары (E2–C6) переносятся на ближайшую доступную октаву; длительности ограничены 1/128 … лонга (превышение при ×1.5 срезается до лонги).
8. **Темп**: для каждой локализации взято характерное значение из диапазона табл. 8 (Allegro 130, Adagio 66, Moderato 110, Andante 76 — как в примерах статьи); `--bpm` переопределяет.

### Обратный перевод

Для каждого звука строится множество «кусочков» последовательности, воспроизводящих его класс высоты и длительность: пара из табл. 2 (с глицином, если нужен акцент), при необходимости — метиониновые модификаторы `Mx`/`xM`, для аккорда — корневая пара + P-дуплекс, для паузы — M-дуплекс табл. 4, для форшлагов — пары + PG/GP/PP. Лучевой поиск (beam search) оценивает октаву и динамику по реальным окнам, как только они определены; лучшие кандидаты прогоняются через прямой алгоритм, сравниваются с целью, и локальная «починка» перебирает отдельные кусочки. Высоты, длительности, паузы, аккорды и акценты воспроизводятся точно; октава и динамика — в подавляющем большинстве звуков (они зависят от соседей на ±3–4 остатка, и одновременное выполнение всех ограничений возможно не всегда — статья отмечает то же самое). Длительности, не входящие в набор «1/128 … 4 с точкой или без», округляются; паузы с точкой разбиваются на две; форшлаги длиннее двух нот укорачиваются; трели и туплеты аппроксимируются.

## English summary

**Abiks** implements the protein-to-music and music-to-protein algorithm of Nadirova & Zhigailov (Heliyon 2026, e45432). Amino-acid pairs encode pitch classes (a degenerate doublet code, Table 2), charged residues change note length (Table 3), methionine encodes rests (Table 4), the hydrophilicity of the six nearest residues sets the octave (Table 5), proline encodes chords (Table 6), α/β propensity of the eight nearest residues sets dynamics (Table 7) and the protein's localization sets the tempo (Table 8). Output: ABC, MIDI, MusicXML; a beam-search reverse translation produces amino-acid sequences from ABC scores and verifies them with the forward algorithm.

```bash
node bin/abiks.js encode examples/insulin.fasta --loc secreted -o insulin.abc --midi insulin.mid --xml insulin.musicxml --table
node bin/abiks.js decode examples/rondo-alla-turca.abc --diffs
node bin/abiks.js serve 8080   # web converter
npm test
```

The implementation is checked against the worked examples of the paper (Fig. 1a, 1b, 4a, 5 and the rules of Tables 1–8). Interpretation choices for the ambiguous points of the paper (fractional note values, window placement at segment ends, dynamics of glycine duplexes, methionine-pair fallbacks, chord voicing) are listed in the Russian section above ("Уточнения реализации").
