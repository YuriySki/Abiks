## Как читать

Каждое правило оформлено одинаково:

- **ID** вида `R-07.2` — глава 7 книги, правило 2. Правила заключения — `R-C.n`, сквозные принципы — `P-n`, шаблоны — `T-n`.
- **Правило** — что делать (или не делать).
- **Почему** — какую проблему это предотвращает.
- **Как применить** — конкретное действие или проверка.
- **Признак нарушения** — как заметить, что правило не выполняется (там, где источник его даёт).

Строки «Схема главы» воспроизводят последовательности из иллюстраций книги.
Машиночитаемый индекс всех правил: [rules-index.yaml](rules-index.yaml).

## Быстрые входы по задаче

- Нужно выбрать, с чего начать: `02` (диагностика, зрелость) → `03` (критерии первого агента) → `09` (матрица выбора T-2).
- Проектируем агента: `03` (определение) → `04` (данные, доступы, стандарт результата) → `09` (паспорт T-1).
- Запускаем пилот: `05` → `07` (экономика) → `09` (готовность к запуску T-8).
- Соединяем несколько агентов: `06` → `09` (минимальный пакет контракта T-4).
- Готовим систему к эксплуатации: `07` (безопасность, наблюдаемость) → `08` (масштаб, дорожная карта) → `09` (контрольная карта T-3).
